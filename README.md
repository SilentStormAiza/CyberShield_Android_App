# CyberShield_Android_App
Security you notice… when it matters. We’re there defending you!
</br></br>
**Description**</br>
CyberShield is a mobile application designed to help citizens:
- Report cybercrime incidents
- Connect them with technical experts and government authorities for verification and recovery.
</br>The app allows:
- Submit cyber incident reports with details and evidence
- Which are then reviewed by technical experts
- Serious cases will be escalated to government authorities for further action
</br>All through the App. Significantly, it will also provide privacy in case of confidential concerns, share victim's info if he/she willing. The application also provides trending scam alerts, and notifications to keep users informed.
</br>Once a case is resolved, users can submit feedback about the resolution process. The system creates a complete workflow from reporting cybercrime to resolving it and collecting user feedback.
